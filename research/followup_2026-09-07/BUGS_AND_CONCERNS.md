# Bugs, methodological concerns, and suspicious results

This register distinguishes historical defects from new findings. Historical corrections are not claimed as work done in this follow-up. Source artifacts and submitted prose were preserved. Detailed evidence is in the [metric audit](audit/AUDIT.md), [probe audit](probe/probe_audit.md), [literature check](literature.md), and the original [chronology](/home/moloch/ouro_project/docs/jlens/history/2026-09-04-opus/RESEARCH_LOG.md).

**Historical defects and retractions encountered while reading.**

| Issue | Consequence and status |
|---|---|
| Controls averaged before the any-layer maximum, while each true label got its own maximum. | Silently inflated excess recovery. Previously fixed; the current calculation gives each control its own any-layer event before averaging. Independent reproduction confirms both normal and cross-loop paths' intended order. |
| Arithmetic controls originally mixed operation words with numeric labels. | Low operation-word ranks made controls too easy. Previously fixed by matching operation status. Current numeric-only evaluation retains same-kind controls. |
| Slot weighting versus item weighting differed across summaries. | Items with several labels received inconsistent weights and tables disagreed. Previously fixed; new analyses average within items before between items. |
| Mirrored operand pairs crossed probe training/test boundaries. | Symmetric sums leaked labels; older probe scores were inflated. Previously fixed. Current folds keep unordered pairs together. |
| Outer-fold class coverage was ignored in older probe comparisons. | Some test labels were impossible for that fold's classifier. Current fair comparison uses the same 576 eligible prompts/39 pairs for every method. The 648-row arrays remain retained. |
| Test-selected or differently selected layer maxima appeared in historical probe comparisons. | An oracle maximum was sometimes read as held-out performance. Current probe choices use inner validation, with untouched outer test folds; native lenses have their own held-out selection rule. The follow-up matches the inner selection sample as a sensitivity. |
| Answer matcher accepted `11` for `1`; saved correctness flags could be stale. | Previously tightened to a character boundary, yielding historical 72/148. This follow-up recomputes from raw continuations; two numeric false positives remain, below. |
| Initial trailing-space/readout-position error. | Prompt tokenization initially placed the readout on an inappropriate lone-space token and altered generation. Historical pilot outputs were discarded; retained strict evaluation uses the shared prompt/target token prefix. |
| Validation at dimension batch 8 exceeded laptop memory. | Could abort a run before fitting. Historical fallback halves the batch. Retained recorder checks report exact parity; no new GPU validation was claimed here. |
| Bootstrap results depended on previous calls to a shared RNG. | Historical code now uses a fresh RNG per calculation and 20,000 draws. Follow-up seeds and resampling units are explicit. |
| Negative modeled variance estimates were silently clipped. | Made fitted mean/scatter summaries appear better behaved than they were. Historical correction exposes invalid moments; this follow-up makes no inference from the clipped values. |
| Modeled scatter was relabeled as directly observed single-prompt Jacobian norms. | Unsupported “cancellation mechanism” claim was retracted in the later record. No direct per-prompt norm evidence was recovered here. |
| Flat hit@10 was interpreted as fit convergence. | A floored binary score can stay flat while ranks improve. Historical rank analyses undermined that wording. Nested N=8–100 fits do not establish convergence or independent-fit variance. |
| Position-reduction comparison used three samples in one arm versus 93 in the other. | Could not isolate diagonal versus position-summed estimation. The claim that estimator choice had been ruled out was withdrawn; a matched experiment is still justified. |
| Whitening/polar-factor controls and conflicting probe learning curves supported premature mechanisms. | A mismatched polar map could perform better; training-size comparisons changed test sets, label coverage and aggregation. The old causal stories are not accepted as evidence. Referenced late probe-curve files were not found at their stated path. |
| Historical exit-convergence claim ignored position dependence. | Lens KL decreases one token earlier but not monotonically at the main token. No general convergence claim follows. The new actual-exit comparison further separates model revision from estimator disagreement. |
| Paid-run and artifact-retention failures; nine later launch attempts. | Earlier rental produced no retained scientific result. Later CPU thread oversubscription made fitting extremely slow, and the all-exit pod result was not retained before timeout. Current exits use the documented local reevaluation, not an invented recovered run. |

**New findings and remaining limits of the main comparison.**

| Issue | Evidence, handling, and effect |
|---|---|
| Decimal false positives survive the corrected matcher. | `div-sub-left` returns `3.8`; `nested4-add-mult-add-div` returns `3.75`; both pass target `3`. Separate strict numeric scoring yields 70/148 instead of 72. Historical outputs remain unchanged; corrected subgroup results are saved. |
| Lexical criterion is not semantic accuracy. | `word-parens` returns `20.` for `twenty`, giving 71 passes under narrow equivalence. Other cases include `daytime`/`day`, a Roman numeral after explanatory text, and `the North Pole`/`north`. Four generated tokens can truncate answers. No exhaustive semantic adjudication is claimed. |
| Two factual tasks use the outdated China-most-populous premise. | `super-populous-capital` and `firstletter-populous-country`; [UN DESA](https://desapublications.un.org/policy-briefs/un-desa-policy-brief-no-153-india-overtakes-china-worlds-most-populous-country) documents the 2023 crossover. Excluding just these two leaves all three early multihop deficits and the final-pass shape. No silent relabeling. |
| Equivalent concepts can remain among controls. | Four rhyme items have their own number concept under a different control name. Number-word/digit aliases also weight some control concepts repeatedly. Merging aliases and excluding equivalent own concepts changes multihop layer effects by at most .022; early deficits remain. [Sensitivity results](audit/sensitivities.md). |
| Controls often include the eventual target and are only partially matched. | Final-target token forms overlap a control in 43/90 multihop and 39/51 arithmetic items. Matching covers task and operation status, not frequency, semantic type or alias count. Excess measures specificity against this background, not contrast with guaranteed unrelated concepts. |
| Curated items share concepts and templates. | No exact duplicate prompts/names, but IID-item sampling is not a design fact. Shared-concept clusters (64/14) and name-prefix clusters (36/15) give sensitivities; neither models every dependence. Early deficits survive; some favorable intervals widen. No downstream task prompts were found in the WikiText fit texts, but broad semantic overlap is not measurable from that check. |
| Any-layer coverage is an oracle estimand. | Different items, labels and controls can succeed at different layers. Current fixed-layer curves ask the separate depth question. The source's same-data `selected_location_ci95_conditional` is not selection-adjusted inference and is not used as a headline here. |
| Many layer and subgroup comparisons. | All 384 main contrasts are retained with an approximate maximum-error simultaneous band. Fixed bands, slopes and correctness interactions remain unadjusted. No positive layer survives the shared-concept simultaneous band. A nominal arithmetic outcome interaction disappears under reasonable sensitivities. |
| Statistical intervals omit fit variation. | They condition on one retained N=100 lens. The older calibration-size runs are nested; calibration randomness, domain mismatch and model-training variation remain unknown. |
| Calibration position and target differ from relevant defaults. | Fitting skips the first 16 tokens; the historical audit counted 99/148 readouts before that position. The estimator averages present/future positional effects, while evaluation asks about a particular prompt position. Anthropic's default Sonnet implementation uses a penultimate target and larger calibration corpus; Ouro here uses the final residual. These are hypotheses to test, not diagnosed causes. |
| Exit fields named `local` are target-relative. | For final J-Lens and LL, `target_ut=3`, so their saved `*_to_local` ranks/KL duplicate final-exit fields. This is a naming trap, not evidence of available current-exit distributions. New tables use actual token IDs for current-exit agreement and leave missing rank/KL cells empty. |
| Identity tails and endpoints can create trivial agreement. | Local lenses are identity at and after their target. Only the source pass is analyzed as its local lens; the main late-layer comparison excludes physical layer 48. Boundary values are shown separately and not called learned accuracy. |
| Full logits/top-k sets were not retained. | Actual-exit KL, true-token ranks, and top-1 IDs suffice for the reported diagnostics. They cannot reconstruct arbitrary top-k set overlaps, pairwise lens rank metrics, or missing current-exit KL. No values were fabricated. |
| Top-1 IDs and rank zero need not coincide under ties. | Saved ranks use an unstabilized argsort; finite-precision ties can rank an argmax token above zero. Agreement uses explicit saved argmax IDs. Rank metrics preserve original tie behavior. |
| Pod and local outputs differ numerically. | 8/148 continuations, 8/592 native exit predictions, 635/28,416 LL and 580/28,416 final-J predictions differ. Each truth comparison uses its own run. Passing/failing membership does not change between these two runs. |
| One pod source hash differs from today's working tree. | Recovered exactly in Git HEAD: differences concern absolute output paths and `empty_cache`, not readout logic. Bundle output hashes match. Resolved provenance discrepancy; not silently ignored. |
| Older and current example ranks differ. | Submitted `iron` rank 979 belongs to the earlier evaluation. N=100 best loop-1 ordinary rank is 132 versus LL's 1. The random sample retains J-Lens wins, both-method failures, and readable wrong answers. |
| Poor exit prediction is not failure of J-Lens's stated objective. | The paper itself separates averaged verbalizability from actual next-token prediction. Local and final lenses also have different targets despite reading the same source state. Our final-exit lens is poor at predicting actual exits; that diagnostic cannot by itself decide intermediate or causal fidelity. |
| Successful readout does not show causal use; outcome strata are observational. | Both lenses sometimes read an intermediate followed by a wrong answer. Passing/failing groups differ in task content. No patching, intervention, causal mediation or monitoring-system test was performed. |

**Additional supervised-probe concerns.**

| Issue | Evidence and handling |
|---|---|
| Training size was described imprecisely. | 576 is eligible test rows. Outer refits use 512–528 rows from 36 pairs; inner fitting has 28 pairs, with eight for selection. Prompt count exaggerates the amount of independent supervision. |
| Seventeen nominal classes create sparse coverage. | Outer eligibility is handled; inner validation still has 16/40/16/16/0 rows whose labels are absent from inner training. Their constant zero score reduces informative validation size but cannot change the probe's selected layer. A scalar target would be a different experiment. |
| Native lenses had more layer-selection examples and uneven token aliases. | Direct matched-selection and one-form checks preserve the loop-1 loss. StandardScaler is fitted only on training data. No held-out feature-fit leakage was found. |
| Default solver tolerance changes predictions without warnings. | Five refits reproduce exactly, but tighter tolerance changes 36/576 eligible predictions, net +10 correct: .594→.611. Original and improved results are retained separately. |
| Four selected C values were at the upper grid boundary. | Adding only C=10, chosen on inner validation, gives .596; one fold adopts it. This bounded check does not rule out every regularization choice. |
| Training-size check is conditional, not a complete learning curve. | Three fixed class-covering half samples use the original full-data-selected layers/C with a mean-loss penalty correction. Same outer rows, but selection was not repeated independently at each size. The gain is imprecise. |
| Probe and native-lens bootstrap selection policies differ historically. | The original report reselects native-lens layers within bootstrap draws but holds probe choices fixed. Both that policy and fully fixed-choice intervals were reproduced; loop-1 loss and loop-3 gain survive. Intervals do not include classifier refitting. |
| The .125 majority baseline is a global frequency, not fold-trained majority. | It equals always predicting 10. Training-fold majorities fall in disjoint test-label holes and score zero; this surprising value was independently checked, not promoted as a useful comparison. |
| Older J-Lens and report provenance is incomplete. | Probe J-Lens is the older 80-prompt fit. Array/cache hashes and selected classifiers reproduce, but the report source grew from 13,203 to 13,613 bytes since its manifest. The old source-validation label is no longer literally current. |
| Historical source wording overstates data limitation. | The old `probe_cv.py` docstring calls it the explanation. Current evidence supports plausibility, not a causal diagnosis. Earlier mutually conflicting audit prose is preserved, not reconciled by choosing the preferred story. |
| Raw generations for all 648 probe prompts are absent from the cache. | Its stored correctness vector was not regenerated or independently semantically checked. It is not used to explain the probe deficit or mixed with the main 148-item stratification. |

**Follow-up implementation and Huginn feasibility.**

- During setup, task bootstrap draws initially used the same seed. Independent task seeds 0 and 1 replaced that accidental coupling before inspecting the final curves; the 384-cell simultaneous band was regenerated and independently verified.
- The probe audit initially failed JSON serialization on NumPy integers. It was fixed and rerun before reporting results; no score changed.
- The independent exit/correctness verifier initially looked for task results at the JSON root and stopped with a `KeyError`. Its schema lookup was corrected to the `tasks` container; the successful rerun found no root scoring discrepancy.
- Different float32 reduction orders give at most about 9.5×10⁻⁷ discrepancy in independently recomputed KL. Some all-one bootstrap intervals end at `1 + 10⁻¹⁵` from floating-point arithmetic. Percentages are rounded appropriately; neither affects a conclusion.
- The four main layer/exit/correctness plot types were visually inspected. Independent scoring and bootstrap checks found no numerical defect in their source results; these checks do not prove all scientific assumptions correct.
- The guessed Huginn architecture v3 URL did not exist; the primary v2 source was used. The raw-logit-lens prior is specific to R4 and numeric-prefix scoring, and its intermediate analysis selects correctly answered cases. It cannot establish a matched advantage over Ouro.
- Huginn's coda is trained at sampled recurrent depths. It lacks Ouro's simultaneous per-pass loss, but “no intermediate supervision” without qualification is misleading. Raw R4 unembedding is not Huginn's native exit readout.
- Huginn's scalar-depth path runs recurrence under `no_grad`; existing local wrappers use inference mode, detach and pool states. Repeated modules need distinct invocation taps, and fitting dimension-batch replicas must share the same random initial state. Otherwise a matrix would combine derivatives from different trajectories.
- Native Huginn `ln_f` is used both before and after the coda; returned latent states are already normalized and detached. Applying the coda helper to those fields can normalize twice at its input. Coda attention needs the entire sequence; R1–R3 coda applications are interventions, not native exits. The initial pilot must also avoid the native attention-mask mismatch with unpadded prompts. [Exact adapter traps](huginn_feasibility.md).
- Local CUDA is unavailable and NVIDIA driver communication fails. Cached weights are structurally complete, but inference memory measurements do not establish that dense Jacobian fitting fits. No Huginn model experiment, paid run, or monitoring comparison was performed.

These issues are not all equally consequential. The remaining numeric matcher errors change correctness counts; dependence and selection limit uncertainty; the strongest negative effect itself survives the independent and sensitivity checks.
