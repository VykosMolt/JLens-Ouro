# Paid-run incident: 2026-09-04

## Outcome

A B300 pod was rented at approximately `$7.89/hour`. Approximately `$52.74` was spent. No fit, validation log, or result artifact from that pod was retained. The account balance later reported `-$0.54`; no pod is currently running and current spend is `$0/hour`.

The lost run is `NOT_RETAINED`. Terminal narration about its validation cannot be used as evidence.

## Causes

- Pod creation was separate from supervision.
- Balance was checked only before creation.
- The kill process did not survive the controlling session.
- There was no continuous balance, budget, runtime, or API-uncertainty policy.
- Results were uploaded only from an exit trap.
- Completed shards were explicitly excluded from the upload.
- Successful completion did not terminate the paid pod.
- Retrieval had no local acknowledgement or hash verification.

`29 seconds * 100 prompts * (47 + 95 + 143 + 191 sources) / 191 = 7,227 seconds`, or 120.45 minutes and approximately `$15.84` at `$7.89/hour`, before validation, evaluation, upload, or teardown.

## Required closure
